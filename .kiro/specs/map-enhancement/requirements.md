# 地圖視覺化增強 — 需求

## 背景
儀表板地圖原本用三格跳色（綠/黃/紅）表示路段壅塞程度，站點大小固定，
缺少專業交通 GIS 系統的精緻度。需要提升視覺表現以增加指揮官對即時狀態的感知。

## 需求
1. 路段顏色改為連續漸變色階（6 段：深綠->亮綠->黃->橘->深紅->暗紫紅）
2. 站點圓點大小依人流數動態縮放（5k=5px, 40k=14px）
3. 路段 hover 加粗效果（5px->9px）
4. 站點 hover 放大 + 其他站點淡化（避免 tooltip 被遮擋）
5. 點擊路段/站點時地圖縮放定位到該實體
6. 加比例尺（右上角，固定 60px 寬，深色主題風格）
7. 點空白處關閉所有 tooltip

## 驗收標準
- 時間軸播放時路段顏色隨飽和度平滑變化
- 站點大小隨人流數即時縮放
- hover/click 互動不會造成 tooltip 被其他元素遮擋
